tools
Looks it up

It reaches for a tool when the answer depends on something it cannot know. Every source it used is cited under the answer.

reference
Offline Wikipedia

A full copy of Wikipedia is served beside it. An encyclopedia question reads that copy and needs no outside request.

houses
An address from public records

Flood maps, roads, schools and loan programmes come from free public services, paced so none of them is hammered. A follow up answers from the cache.

files
Attachments

PDFs, spreadsheets, documents, code and logs, by drag and drop or the picker. Each is read into the turn and the file itself is dropped.

pictures
Draws on the same card

Ask for a picture and an image model takes the card while the chat model waits. A panel shows each stage until it loads.

privacy
History, or none at all

Conversations are kept where you can search and delete them. Incognito writes nothing, here or at the model gateway.
