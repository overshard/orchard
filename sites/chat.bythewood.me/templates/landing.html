A conversation with a model running on hardware you own.

No API key, no third party, and nothing leaving the house. It reaches for a tool when the answer depends on something it cannot know, reads the files you give it, and keeps the thread in a database you can delete.

  • Ten tools, all keyless: search, page fetching, weather, markets, scores, odds, music, conversion and arithmetic.
  • Attachments by drag and drop or picker. PDFs, spreadsheets, documents, code and logs, read into the turn and never stored.
  • Incognito writes nothing down, verified by counting rows either side of a turn.
  • Compaction summarises the oldest exchanges once the window fills, so a long thread keeps working.
