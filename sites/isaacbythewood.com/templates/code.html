orchard

BSD-2
{{- with .Topo }} {{- end }}

Each site is its own Go module with its own copy of the small HTTP layer they all share, so any one of them can be lifted into its own repo and still build. Vite builds the assets, Go embeds them, Typst renders the PDFs and social cards, and most sites ship as a single binary in an empty image.
