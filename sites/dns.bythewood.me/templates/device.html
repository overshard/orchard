android · private dns
  1. Settings, Network & internet, Private DNS.
  2. Pick Private DNS provider hostname and paste the name below.
  3. Android won't fall back, so if the box is down switch it to Automatic.
{{$p.DoT}}
{{else if eq .W "apple"}}
iphone, ipad, mac · profile
  1. Open this page on the device and download the profile.
  2. iPhone and iPad, Settings, Profile Downloaded, Install. Mac, System Settings, Privacy & Security, Profiles.
  3. It covers Wi-Fi and cellular. Remove the profile to undo it.
Download the profile
{{else if eq .W "browser"}}
browser · dns over https
  1. Chrome and Edge, Settings, Privacy and security, Security, Use secure DNS, With Custom.
  2. Firefox, Settings, Privacy & Security, DNS over HTTPS, Max Protection, Custom. Increased Protection falls back to plain DNS and goes around this.
  3. Paste the URL below. The browser then asks here whatever network it's on.
{{$p.DoH}}
{{else if eq .W "windows"}}
windows 11 · every app
  1. Settings, Network & internet, the adapter, Hardware properties, DNS server assignment, Edit, Manual.
  2. Turn on IPv4, put the first address below as Preferred DNS, set DNS over HTTPS to On (manual template), paste the template and turn off fallback to plaintext.
  3. Same again with the second address as Alternate.
  4. In Firefox, Settings, DNS over HTTPS, Off, so it uses the system's.
{{$p.DoH}}

{{range $p.IPs}}Add-DnsClientDohServerAddress -ServerAddress {{.}} -DohTemplate {{$p.DoH}} -AllowFallbackToUdp $False -AutoUpgrade $True
