Set it up

one token, every way in
android · private dns

Settings, Network & internet, Private DNS, then Private DNS provider hostname. Android talks DNS over TLS on port 853 to this name and nothing else, and it doesn't fall back, so if the box is down switch it back to Automatic.

{{.DoT}}
browser · dns over https

Chrome and Edge, Settings, Privacy and security, Security, Use secure DNS, With Custom. Firefox, Settings, Privacy & Security, DNS over HTTPS, Max Protection, Custom. The browser then asks here whatever the network it's on says.

{{.DoH}}
windows 11 · every app

Settings, Network & internet, the adapter, Hardware properties, DNS server assignment, Edit, Manual. Turn on IPv4, put the first address as Preferred DNS, set DNS over HTTPS to On (manual template), paste the template and turn off fallback to plaintext. Same again with the second address as Alternate. Windows needs the addresses only to know which server the template belongs to.
