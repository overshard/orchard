pass · passwords · self-hosted

Every password, on my own server.

A Bitwarden compatible server for my own phone and browsers, running Vaultwarden. The vault is encrypted on each device before it gets here, so the server only ever holds ciphertext, and this page shows who signed in, from where and on what.
