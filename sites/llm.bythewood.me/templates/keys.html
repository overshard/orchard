Using it

API

Point any OpenAI shaped client at http://orchard-llm:8000/v1 on the bridge, or https://llm.bythewood.me/v1 from anywhere else, and send the key as a bearer token.

curl https://llm.bythewood.me/v1/chat/completions \
  -H "Authorization: Bearer $LLM_KEY" \
  -d '{"messages": [{"role": "user", "content": "hello"}]}'
