New push token. This is the only time it is shown.

Use it as the password. The username is ignored, so type anything:

git remote add origin {{$d.CloneURL}}/<name>.git
git push -u origin main

To avoid retyping it, let git remember it: 

git config --global credential.helper store
The token is stored in clear in ~/.git-credentials, so treat that file as the secret it is.

Push tokens

A token is the password half of an HTTP Basic credential, which is the only scheme git natively stores and replays. It is a random value, not a password, and only its hash is kept here. Revoking one takes effect on the next push.
