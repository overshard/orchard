once
A reminder at a time

Fires once and removes itself. A push that doesn't land is tried again for half an hour before it gives up.

repeat
Plain cron lines

Five fields read on the local clock, so a 9am job stays at 9am across the clock change. The form previews the next three times.

checks
A model does the looking

A check is a prompt with web search behind it. It decides whether the answer is worth a push and stays quiet when it isn't.

snooze
One button on the push

Every notification carries a snooze that sends it again in an hour, straight from the lock screen.

api
Made to be scripted

A key per caller and a small JSON API to add, change, run and remove jobs, so an assistant can set one up mid conversation.

history
Every run written down

What fired, what went out and what failed is kept for a year, so a reminder that never arrived can be traced.
