Everything goes to one endpoint.

All events are sent as JSON to a single POST /collect/ endpoint. The site tag pushes page_view, click, scroll, and page_leave automatically, and everything else is a one-liner on collectorQueue, or a raw HTTP call from any language.

Collect custom clicks

Put data-track on any element. A click on it, or on anything inside it, sends an event under that name.

<button data-track="signup_cta_click">Sign up</button>
Collect custom page views

Use this for SPA route changes, funnel checkpoints ("invoice paid"), or any meaningful page-level moment. Push once per visit:

(window.collectorQueue = window.collectorQueue || []).push({event: 'checkout_success'});
Attach custom data to any event

Every event is stored as JSON in an extra column. Add whatever keys you need, no migration required, query with SQLite JSON1 json_extract(extra, '$.user_segment') later.

(window.collectorQueue = window.collectorQueue || []).push({event: 'admin_page_view', data: {user_segment: 'admins'}});
Send events over raw HTTP

The collector endpoint is plain JSON, so any HTTP client will do. Include a valid collector_id, event, and optional data.

curl -X POST -H 'Content-Type: application/json' \
  -d '{"collector_id": "PROPERTY_COLLECTOR_ID", "event": "custom_app_event", "data": {"app_id": 4}}' \
  YOUR_COLLECTOR_SERVER/collect/
Server-side events (Python)

Any backend, any library, any runtime. Here's a Python example using requests:

import requests

requests.post(
    'YOUR_COLLECTOR_SERVER/collect/',
    json={'collector_id': 'PROPERTY_COLLECTOR_ID',
          'event': 'subscription_renewed',
          'data': {'plan': 'pro', 'mrr': 49}}
)
