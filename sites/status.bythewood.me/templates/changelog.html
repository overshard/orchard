Shipped changes, incidents, and the occasional tease for something coming.

2026-08-26
  • Rewrite the backend from Rust to Go and move it into the orchard monorepo, alongside the other sites and the shared Cloudflare Tunnel and Caddy. html/template replaces minijinja, modernc.org/sqlite replaces sqlx, and the frontend carries over untouched. The schema is unchanged, so property UUIDs survive a second port and existing public status URLs keep working
  • Remove outage email entirely. Direct-to-MX delivery cannot work from a residential address: outbound port 25 is blocked, there is no control over the PTR record, and consumer ranges are on the Spamhaus PBL by default. Alerts now publish to a self-hosted ntfy topic, which never crosses a third party
  • Remove the Discord webhook along with it. The one message that has to arrive when your own infrastructure is broken should not depend on somebody else's server
  • Fix the redirect-chain check, which had never once fired: the crawler recorded a one-element chain and the check tested for more than two, so the condition was unreachable
  • Sort the crawler's duplicate-title, duplicate-description and duplicate-h1 groupings, and the Lighthouse score tiles. All four were iterated out of unordered containers and could rearrange themselves between page loads
  • Answer 405 with an Allow header on a wrong method, instead of 404
  • Kill the whole Lighthouse process group on timeout, so a wedged audit can no longer leak a Chromium per day
  • Drop BASE_URL, PORT, STATUS_ROOT, STATUS_DATA_DIR and STATUS_COOKIE_SECRET. STATUS_PASSWORD is the only environment variable left, because it is the only one that is a secret
2026-05-09
  • Rewrite the entire backend from Django to a single statically-linked axum binary in Rust. sqlx + SQLite directly, minijinja for templates, no more Gunicorn or separate scheduler process. Property UUIDs are preserved so existing public status URLs keep working
  • Drop the multi-user accounts model. Auth is now a single operator password from .env with signed-cookie sessions and SameSite=Strict instead of CSRF tokens
  • Port the SEO crawler from requests + BeautifulSoup to reqwest + scraper. The 38 ranked checks (SEO, links, sitemap, accessibility, content, performance, security) match the original Python output
  • Switch alert email to lettre + hickory-resolver, still opportunistic STARTTLS direct-to-MX on port 25; Discord webhooks are plain HTTP POST
  • Add a ./status migrate <django.sqlite3> subcommand that imports an existing Django SQLite into the new schema while preserving Property UUIDs
  • Run the lighthouse CLI through bun run --bun so the runtime image drops nodejs and npm; chromium stays for lighthouse only
  • Probe Content-Encoding with a non-decompressing client so response_ms reflects the wire payload, not the decoded body
  • Fix the mobile nav menu being clipped by the fixed navbar height
